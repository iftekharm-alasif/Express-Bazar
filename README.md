# 🛒 Express Bazar

**Express Bazar** is a modern and responsive grocery and fresh market price tracking website built with Next.js. It helps users explore products, check today's market prices, browse categories, and track price changes through a clean and user-friendly interface.

## 🔗 Live & Relevant Links

- **Live Website:** ---
- **GitHub Repository:** https://github.com/iftekharm-alasif/express-bazar

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- Lucide React
- React Hot Toast
- REST API

## ✨ Main Features

- 🛒 Browse grocery and fresh market products
- 💰 View today's market prices
- 📂 Explore products by category
- 📈 Track increasing and decreasing prices
- 🔃 Sort products by price
- 🔐 Authentication with email and password
- 🌐 Google and GitHub social authentication
- 👤 Update profile information and image URL
- 📱 Fully responsive design
- 🎨 Clean and modern user interface

## 📦 Installation

Install project dependencies:

```bash
npm install
```

## 🚀 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/iftekharm-alasif/express-bazar.git
```

### 2. Navigate to the project directory

```bash
cd express-bazar
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory and configure the environment variables required for authentication and database access.

**Note:** Never commit secret keys or database credentials to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
